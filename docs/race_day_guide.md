# Race-day guide

This is for whoever is running the start box. You don't need to know anything about computers.
Print it and keep it in the box.

> **The camera is only an aid. The real flags and sound signals are the official signals.** If the
> screen and the flags disagree, the flags are right, and keep racing as normal. Never time a
> start from a TV: its picture runs several seconds behind.

## Before racing

Tick these off about 30 minutes before the first start.

- [ ] **Turn on the camera.** Make sure it's pointing at the line, and hasn't been knocked.
- [ ] **Start the system:** double-click **Start Camera** on the laptop's desktop, then press
  **Start streaming**.
- [ ] **Check the picture** on the laptop or the TV. You should see:
  - the river, not a black screen saying `CAMERA SIGNAL LOST`
  - the right time and date in the top left corner
  - the red start line, lying along the real line
- [ ] **Open the control page on your phone**, if you're using it: go to the address below and log
  in. Your phone must be on the club WiFi.

- [ ] **Check the top right corner** shows today's first start, or `READY`.

If the line doesn't match the real line, the camera has moved. Carry on racing, and tell the person
named above.

## During racing

The laptop and the phone have the same buttons. Use either one, as they always show the same thing.

| What's happening | Press | What you'll see |
|---|---|---|
| Starting the sequence by hand, when the corner says `READY` | **Start now** | The 5 minute countdown starts straight away |
| The start needs to be later | **+1**, **+5** or **+10** | The countdown moves on, and later starts move too |
| You delayed by too much | **-1** | The start comes 1 minute sooner |
| Postponing (AP) | **Postpone** | `POSTPONED`, and the AP flag |
| Ending the postponement | **Resume** | The next warning signal comes 1 minute later |
| Boats over the line at the start | **Individual recall** | Flag X. Press **Clear X** when it comes down |
| General recall | **General recall**, then confirm | First Substitute, and the class starts again |
| Missing out the next class | **Next start**, then confirm | The countdown moves to the class after |
| Abandoning | **Abandon**, then confirm | `ABANDONED`, and flag N. Press **Start now** to run all the sequences again |

**Press these at the same moment as you make the real signal.** The screen follows the buttons, not
your flags.

If a button doesn't seem to work, look at the message on the screen, which says why, such as
"No class has started". Nothing has gone wrong, and nothing has changed.

### Reading the corner of the picture

| You see | It means |
|---|---|
| `Merlin Rocket -03:12` | 3 minutes 12 seconds until that class starts |
| `Merlin Rocket +02:05` in green | That class started 2 minutes 5 seconds ago |
| `Merlin Rocket 11:30:00` | That class starts at 11:30. The countdown appears at its warning signal |
| `READY` | Waiting for you to press **Start now** |

## After racing

Press **Stop streaming**, close the window, and shut the laptop down. If it asks about saving
changes, choose **Discard**, unless you've been told to change something.

## If something looks wrong

Keep racing using the flags, and don't worry about the camera until you have time.

| What you see | What to do |
|---|---|
| Black screen saying `CAMERA SIGNAL LOST` | Check the camera has power. It comes back by itself, usually within a minute of the camera or WiFi returning |
| Red `CONNECTION LOST` on the phone | Check the phone is on the club WiFi. The camera carries on without the phone |
| The phone warns the connection isn't private | Expected for this page, if it's the address above. Choose **Advanced** or **Show details**, then continue. If it's any other address, stop and ask |
| The phone says `Too many attempts` | Wait a minute, then try the password again |
| The TV page is black or keeps loading | Wait a minute, then reload the page. Check the system has started, and on the laptop that it says `Stream: ON` |
| The time on the picture is wrong | Tell the person named above. Don't rely on the picture's time |
| The laptop window has closed | Double-click **Start Camera** again. Today's racing carries on where it was |
| A button says to stop the stream first | You're trying to change a setting. Leave settings alone during racing |
| Anything else | Turn it all off, then start again from the top of this page. If it still doesn't work, race without it |
